# Tesseract provides words and geometry; reading order comes from local blocks checked by AI

Tesseract 5 (`ces`, tessdata_best) is the single source of words, word boxes and per-word confidence: in the benchmark (docs/research/ocr-engine-benchmark.md) it had the tightest boxes, usable confidence, and it still produced boxes for blurred words near the binding. Tesseract's own block order is unusable for multi-column pages, so blocks are built locally from its lines and words, and Claude receives one page preview with numbered blocks per page and returns only their grouping into articles and their order. We rejected Surya's layout model despite its good ordering because it silently skipped whole articles, needs a heavy vLLM install and has a restrictive weights licence; building blocks from all detected words guarantees coverage. PaddleOCR may later be added as a second reading of problem spots, never as a geometry source.
