# Faithful transcription: reconstruct the illegible, never correct the legible

The text layer reproduces exactly what is printed, including the publisher's own typos and spelling. AI is only allowed to reconstruct problem spots (text the local OCR could not read reliably); it must not "improve" legible text. Publisher errors are kept and listed in the report instead. We chose this because the OCR PDF must stay a trustworthy record of the source, and an AI that is allowed to correct would silently rewrite historical text.
